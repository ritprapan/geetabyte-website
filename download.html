Install in 5 steps

  1. Download GeetabyteERP-Setup.exe and open it.
  2. If Windows shows “Windows protected your PC”, click More info, then Run anyway.
  3. Allow the change when Windows asks for permission, then click Next and Install.
  4. Wait while the setup prepares the database. This takes about a minute.
  5. Open GeetabyteERP, create your admin account and start your 30-day trial.
